# Practica Ransomware Seguridad Informatica

Este es un servidor que se encarga de gestionar el envio de las claves para el desbloqueo de la maquina victima.

> El objetivo de este programa es completamente educativo para enteneder como funciona un software de este estilo y poder aplicar tacticas de proteccion frente a estos casos.

## Como funciona 

Este software se compone de 2 fases:

1. El usuario entra y realiza el pago.
2. El usuario descarga la llave privada para desbloquear su maquina.
